# Card data format (the "bottom half")

Every card we serve is a real printed card. Next to its art there is a card-data JSON describing the text half of the card: name, HP, attacks and so on. It's generated for every card even when the display only shows the art, so the bottom half can be turned back on at any time. In the binder, the bottom half stacks under the art like a real card (toggle: `v`).

## Location
`packs/<pack>/cards/<card-id>.json`, where `card-id` is the pokemontcg.io id (for example `swsh7-215`, `base1-58`). The art that goes with it is `packs/<pack>/art/<card-id>.json` (ART_FORMAT).

It's generated by `tools/fetch_cards.py <card-id>...` from the pokemontcg.io v2 API, and the fields are copied verbatim. Whether the generated card text is committed to the public repo or fetched at install time is still open, because the text is copyrighted. Until that's decided, generated files stay local.

## Schema
```json
{
  "id": "swsh7-215",
  "name": "Umbreon VMAX",
  "supertype": "Pokémon",
  "subtypes": ["VMAX"],
  "hp": "310",
  "types": ["Darkness"],
  "evolvesFrom": "Umbreon V",
  "abilities": [{"name": "...", "text": "...", "type": "Ability"}],
  "attacks": [{"name": "Max Darkness", "cost": ["Colorless", "Colorless"], "damage": "160", "text": ""}],
  "weaknesses": [{"type": "Grass", "value": "×2"}],
  "resistances": [],
  "retreatCost": ["Colorless", "Colorless"],
  "rules": ["VMAX rule: ..."],
  "flavorText": "",
  "set": {"id": "swsh7", "name": "Evolving Skies", "printedTotal": 203},
  "number": "215",
  "rarity": "Rare Rainbow",
  "artist": "KEIICHIRO ITO",
  "tier": "rare-rainbow",
  "images": {"large": "https://images.pokemontcg.io/swsh7/215_hires.png"}
}
```

`tier` is ours: the tier id for the printed rarity (one tier per real rarity, defined in `packs/pokemon/pack.json`). Every other field is the API's.

## Rendering the bottom half (terminal)
- The width matches the art above it, and the text wraps inside a box drawn in the tier's frame colour.
- **Rows:**
  - **Header:** name, subtype badge (V/VMAX/ex), HP and type glyph.
  - **Abilities:** each ability, labelled.
  - **Attacks:** cost as coloured energy glyphs, then name, then damage, with the text wrapped under it.
  - **Footer:** weakness / resistance / retreat, then set, number, rarity symbol and artist.
- Energy glyphs are one cell each: `●` in the type's colour. Emoji are avoided because they are two cells wide.
